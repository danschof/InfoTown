Without a label

Monday

Famous last words.

Wednesday

A comment comes back. Then another. Each new copy gets a slightly more desperate name.

Dave: Four of them?! Which one's the latest?

Thursday

He picks "latest USE THIS". Of course he does. It's the copy Alex was still scribbling on, and nothing on it says draft.

Friday

The document controller: Which project? Which area? Is it even approved? I can't file this.

Slowly losing the will to live.
