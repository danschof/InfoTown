Four files called FINAL

The same drainage drawing, two weeks before it goes anywhere near site.

So far

Without a label

Monday

I'll call it FINAL. I know what it is.

Alex, designer. Famous last words.

Wednesday

A comment comes back. Then another. Each new copy gets a slightly more desperate name.

Thursday

Four of them?! Which one's the latest?

Dave, site manager

Thursday

He picks "latest USE THIS". Of course he does. It's the copy Alex was still scribbling on, and nothing on it says draft.

Friday

Which project? Which area? Is it even approved? I can't file this.

The document controller, slowly losing the will to live

The result

Two hours of phone calls to work out which drawing was right. Next week? Same again.

Same week, with a label

Wednesday

Alex fills in the label when sharing it on the CDE. It takes about a minute. One whole minute.

Thursday

P03, S2. That's for information, not for building. I'll wait for the approved one.

Dave can tell without ringing anyone. Miracles do happen.

Six months later

Anyone can search for 0042 and see every version in order, even after Alex has left for a better-paid job.

Without a labelFour files called FINAL, nobody sure which is right, and a parcel sulking in the in-tray.
With a labelOne parcel and one name. Anyone can tell what it is, whether it's the latest and what it's for.
