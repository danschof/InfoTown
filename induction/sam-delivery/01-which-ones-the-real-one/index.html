A town can have many buildings, but only one Records Office everyone agrees to trust. Two post offices both claiming to be the real one is how parcels go missing.

Sam's view: one Records Office, and every other building's job written on its door.

The scene

Every district has its buildings

Each district runs on its own buildings: the systems that part of the business works in. Engineering has the Design System, Commercial has the Commercial System, and so on. One building, the Records Office, sits in Information Governance and serves every district. Every building keeps information, but each one does a different job. Some are built to last. Some are built for one project and taken down at the end. And some information never reaches a building at all: it stays in someone's bag.

  • Which system is the single source of truth, and where is that agreed?
  • Pick a joiner and a leaver: when did their access start and stop?
For the audit What good evidence looks like
  • The master CDE named in the confirmed plan.
  • A test record from before go-live.
  • An access log showing joiners and leavers.

From the standard
ISO 19650 The CDE, set up and tested

ISO 19650 expects one common data environment for the project, set up and tested before information starts moving, with the rules for what goes where agreed up front.

One agreed CDEThe master. Everything shared or published lives there
