The right way

Three months later…
Forty pages

Marcus: It's short. Is that allowed?

Emilia starts from what the pump team and Grace need, asking of every line: who uses this, and what for? Marcus, the client's project manager, reads all forty pages.

Now there is: The order, written with the people who'll run the station (the information requirements). The old station's records as library copies (reference information). The data the owner runs on (the asset information requirements).

What's going on here

The order is what every bidder will price and every firm will deliver against, so every line in it costs money. An order copied from somebody else asks for the wrong things and misses the right ones. A short order where every line has a reason, written with the people who'll use the information, gets the client what it needs and nothing it'll throw away.

In the town See it in the town: forty pages or nine hundred?

The need from the pump hall now becomes the order: the thing Client Town will send out to whoever builds the station. Alongside it go the old station's 1974 drawings as library copies, there to read but never to edit. Page twelve sets out the data the owner runs on, the eleven things Grace's team needs about every pump, valve and chamber, which is the reason the whole order exists.

Fix it Working to a borrowed order? Find the lines that matter.
  1. List the fields the owner's team actually uses, and who uses them.
  2. Ask the client which unused fields can be dropped, in writing.
  3. Agree the client's own asset numbers before any data is collected.

A note for the information manager: Every line in an order costs money to deliver, so a short list of what's really used is worth more than the full 1,400.
